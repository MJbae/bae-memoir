# 『내 논을 파는 한이 있어도』 독정RPC 쌀 구매 경로 제안서

- **문서 성격**: 자전소설 서재에 독정RPC 프리미엄 쌀의 구매 경로(네이버 스마트스토어·쿠팡)를 독자 거부감 없이 잇는 노출 방안과 수익화 방안
- **대상 범위**: 회차 끝 화면, 홈 '함께 읽을 글', 판매 채널 링크 구성, 정기구독·선물 상품
- **작성 일자**: 2026년 10월 8일 (수수료·지침·단속 일정은 같은 날 조회한 공개 자료 기준)
- **진행 상태**: 제안 단계. 판매자와 주력 품목을 확인한 뒤 구현

---

## 1. 요약

구매 경로는 광고가 아니라 작품의 **후기(그 후의 이야기)**로 둡니다.

| 질문 | 제안 |
|:---|:---|
| 어디에 | 이야기가 오늘의 독정RPC에 닿는 **23화 끝, 외전(마지막 화) 끝, 홈 '함께 읽을 글'** 세 곳에만 둡니다 |
| 어떻게 | 기존 수채화·글꼴·보조 버튼을 그대로 쓴 조용한 카드로 만들고, **첫 줄에 가족이 운영하는 회사임을 밝힙니다** |
| 어떤 링크로 | 일반 상품 주소 대신 **판매자 전용 링크**(네이버 마케팅 링크, 쿠팡 마이샵 다이렉트 링크)를 겁니다 |

수익을 키우는 방법은 세 가지입니다.

1. **판매자 전용 링크**로 같은 판매에서 내는 수수료를 줄입니다. (마진)
2. **정기구독과 알림받기**로 한 번 산 독자를 다달이 받는 독자로 바꿉니다. (재구매)
3. **선물 에디션과 포장 QR**로 선물 받은 사람을 새 독자이자 새 고객으로 만듭니다. (객단가·신규 고객)

## 2. 배경과 목표

### 2.1 서재와 독정RPC

- 이 서재는 [배병희 자전소설](../배병희_자서전.md)(프롤로그 · 6부 23화 · 에필로그 · 외전)을 가족이 휴대폰으로 함께 읽는 곳입니다. 수채화 삽화, 넉넉한 글씨, 조용한 읽기 화면이 특징입니다.
- 원고에 따르면 독정RPC는 배병희가 1983년 인수한 새마을정미소에서 출발했습니다. 2003년 민간 자체 조성 미곡종합처리장(RPC) 승인을 받았고, 2014년 '농업회사법인 독정 RPC 유한회사'로 전환했습니다. 네 아들이 경영·영업·계약재배·정밀 가공을 나눠 맡아 왔습니다(21~23화).
- 작품의 중심이 쌀과 볏값이므로 상품은 이야기 바깥의 광고가 아니라 **이야기의 현재**입니다. 이 제안은 이 점에서 출발합니다.

### 2.2 목표

1. 독정RPC 프리미엄 쌀의 구매 경로를 서재 안에 둡니다.
2. 독자가 광고로 느끼지 않게 합니다.
3. 지금의 디자인(색, 글꼴, 간격, 버튼 체계)을 바꾸지 않습니다.
4. 같은 노출에서 얻는 수익을 최대화합니다.

## 3. 조사 결과

### 3.1 현재 판매 현황

| 채널 | 확인 내용 |
|:---|:---|
| 쿠팡 | '독정RPC 경기미 행복이든 쌀 상등급' 상품 확인. 34,900원, 2025년산, '한 달 400명+ 구매' 표시(검색 엔진 스냅숏 기준). 판매자는 확인하지 못함 |
| 가격비교 | 다나와 기획전에 2024년 햅쌀 행복이든 경기미 10kg, 에누리에 2019 행복이든 경기미 10kg 이력 |
| 기타 쇼핑몰 | '독정RPC 경기미 백진주 쌀' 판매 페이지 이력(17,900원) |

### 3.2 채널별 수수료 구조

| 연결 방식 | 판매자 부담 (VAT 별도) | 적용 조건 |
|:---|:---|:---|
| 네이버 일반 상품 주소 | 판매수수료 2.73% + 결제수수료 | 검색·스토어앱 등으로 들어온 주문 |
| **네이버 마케팅 링크** | 판매수수료 **0.91%** + 결제수수료 | 판매자센터에서 발급한 링크로 들어와 **같은 방문에서** 결제 |
| 쿠팡 일반 상품 주소 | 카테고리 판매수수료 4~11% | 2025년 국정감사에서 농축수산식품 10.6%로 언급 |
| **쿠팡 마이샵 다이렉트 링크** | 운용료 **3.5%** | 다이렉트 링크로 들어와 **24시간 안에** 구매. 마이샵에는 아이템위너 상품만 노출 |
| 쿠팡 파트너스 | 판매자 수수료와 별개로 링크 주인에게 약 3% 지급 | 제3자 제휴 프로그램, 24시간 기준 |

- 네이버 요율은 2025년 6월 2일 개편 기준입니다. 브랜드스토어라면 일반 3.64%, 마케팅 링크 1.82%입니다.
- 네이버 마케팅 링크는 `mkt.shopping.naver.com` 형태로 발급되고, 개별 상품 주소로 들어온 주문에도 적용됩니다. 상품 상세처럼 네이버 내부 지면에 넣으면 어뷰징으로 봅니다.
- 링크로 들어왔다가 나간 뒤 다시 와서 산 주문은 0.91% 대상에서 빠집니다. 그래서 스토어 홈이 아니라 **상품 페이지로 바로** 연결합니다.
- 쿠팡 공식 안내 원문: "마이샵 다이렉트 링크로 유입된 고객이 24시간 내 구매하는 경우 카테고리별 판매 수수료(4~11%)를 부과하지 않습니다." "마이샵 운용료(3.5%)만 부과됩니다."

### 3.4 시장 맥락

- **쌀 소비는 줄고 있습니다.** 2025년 1인당 연간 쌀 소비량은 53.9kg으로 1962년 집계 이후 가장 적고, 전년보다 3.4% 줄었습니다. 판매량보다 객단가·재구매·선물이 수익을 좌우합니다.
- **그래도 꾸준히 다시 삽니다.** 같은 기준으로 2인 가구는 한 달에 약 9kg을 먹습니다. 정기구독과 잘 맞는 물건입니다.
- **선물 수요가 있습니다.** 2022년 보도에서 한 백화점은 추석 쌀 선물세트를 전년의 두 배로 늘렸고, 당시 최근 명절의 쌀 선물세트 실적은 전년보다 44.5~71.3% 늘었습니다.
- **이야기가 값을 바꿉니다.** Significant Objects(2009)는 중고 물건 100개(총 128.74달러)에 짧은 이야기를 붙여 이베이에 올렸고, 3,612.51달러에 팔았습니다. 그 이야기들은 지어낸 것이었고, 이 작품은 실화입니다.

### 3.5 확인하지 못한 것

- 독정RPC의 스마트스토어 운영 여부와 쿠팡 상품의 실제 판매자
- 네이버 마케팅 링크에 NT 파라미터를 붙여도 0.91%가 유지되는지
- 쿠팡 파트너스로 판매자 본인 상품을 홍보해도 되는지에 대한 명시 조항
- 수수료율 원문. 대부분 보도와 업계 정리 글 기준이므로 스마트스토어센터와 쿠팡 윙 공지로 최종 확인이 필요합니다.

## 4. 노출 방안

### 4.1 다섯 원칙

1. **다 읽은 뒤에만 보입니다.** 회차 끝 이동 버튼 아래에만 두고, '다음 화'는 계속 주 버튼으로 둡니다.
2. **이야기가 오늘에 닿는 회차에만 둡니다.** 한 번 완독하는 동안 많아야 세 번 보입니다.
3. **후기처럼 보이게 만듭니다.** 기존 수채화, 본문 글꼴, `--soft` 배경, 보조 버튼 스타일만 씁니다. 가격, 할인율, 배지, 빨간색, '지금 구매'는 쓰지 않습니다. 가격은 자주 바뀌어 금방 틀린 정보가 되므로 사이트에 적지 않습니다.
4. **관계를 첫 줄에 밝힙니다.** '가족이 운영하는 독정RPC'라는 표시는 공정위 지침의 첫머리 표시이면서 이야기의 연장입니다. 숨기면 광고가 되고, 밝히면 후기가 됩니다.
5. **거절하기 쉽게 둡니다.** 카드에 '접기'를 두고, 접은 독자에게는 다시 보이지 않게 브라우저에 기억합니다.

### 4.2 배치

| 위치 | 형태 | 근거 |
|:---|:---|:---|
| **외전 끝** ('끝' 아래) | 수채화 카드. 기존 삽화 `ep22-02`(출하를 기다리는 포장 쌀) 재사용 | 작품이 "세상을 배불리 먹여 살린 밥상"으로 끝나서 오늘의 밥상으로 자연스럽게 이어짐 |
| **23화 끝** | 글 두 줄과 버튼 | 본문의 저온 사일로, 색채선별기, 밀폐형 도정 라인이 곧 품질의 근거 |
| **홈 '함께 읽을 글'** | 목록 한 줄 "그 후의 이야기: 오늘의 독정 들녘" → 문서 한 편 | 지금 비어 있는 기존 칸을 씀. 표지·작품 소개·목차는 건드리지 않음 |
| 21화 끝 (선택) | 각주 한 줄 | 본문의 '2002년 직거래 인터넷 홈페이지'가 지금의 온라인 스토어로 이어짐 |

**넣지 않는 곳**

| 위치 | 이유 |
|:---|:---|
| 본문 문단 사이, 삽화 앞뒤 | 읽는 흐름을 끊고 이야기를 광고로 바꿉니다 |
| 상단 툴바, 설정 시트 | 읽기 도구의 성격을 흐립니다 |
| 팝업, 토스트, 하단 고정 배너 | 전형적인 광고 형식이라 거부감이 가장 큽니다 |
| 홈 표지, 작품 소개, 목차 | 작품의 첫인상을 상점으로 바꿉니다 |
| 프롤로그~22화 (21화 각주 제외) | 이야기가 아직 오늘에 닿지 않았습니다 |
| 18화 | 논을 팔아 볏값을 치른 감정의 정점이라, 희생을 판매에 이용한다는 인상을 줍니다 |
| 에필로그 | 작품의 정서적 마무리이므로 비워 둡니다 |
| 공유 미리보기(OG 이미지·설명) | 카카오톡으로 퍼지는 것은 작품이어야 합니다 |

### 4.4 문구

| 쓸 말 | 피할 말 |
|:---|:---|
| 지금도, 이어 가는, 찧어 보냅니다, 들녘, 밥상처럼 작품 안에서 쓰는 말 | 특가, 최저가, 한정, 품절 임박, 지금 구매. [소제목 제안서](소제목_가독성_개선_제안서.md)에서 걸러낸 '상생' 같은 표어투 |

- 화면 예시의 문구는 예시입니다. '저온 저장', '지금도 찧어 보냅니다', '주문 후 도정' 같은 표현은 실제 공정과 맞을 때만 씁니다.
- 22화의 고시히카리 대목 근처에는 다른 품종 상품을 두지 않습니다. 회차 내용과 상품 품종이 다르면 품종을 잘못 알리는 표시로 읽힐 수 있습니다.
- 상품 줄(품목·연산)은 판매 페이지와 똑같이 적고, 햅쌀로 바뀌면 함께 고칩니다.

| [`scripts/prepare-content.mjs`](../scripts/prepare-content.mjs) | `afterword.json`을 검증해 카탈로그에 넣습니다. 회차 ID·삽화 ID가 없거나 링크가 https·허용 도메인이 아니면 빌드를 멈춥니다(음악·삽화 ID 검증과 같은 방식) |
| `site/.vitepress/theme/components/AfterwordNote.vue` (신규) | 라벨·제목·본문·상품 줄·버튼·접기로 된 카드 |
| [`EpisodeEnd.vue`](../site/.vitepress/theme/components/EpisodeEnd.vue) | 이동 버튼(`nav`) 아래에서 설정된 회차에만 카드를 그립니다 |
| [`Icon.vue`](../site/.vitepress/theme/components/Icon.vue) | 외부 링크(↗) 아이콘을 추가합니다 |
| [`style.css`](../site/.vitepress/theme/style.css) | 카드 스타일. 기존 토큰(`--soft`, `--line`, `--muted`, `--link`)과 글자 크기 변수만 씁니다 |
| `content/afterword.md` (신규) | 후기 문서. 프론트매터에 `id: afterword`만 주면 `/read/afterword.html`과 홈 '함께 읽을 글' 항목이 자동으로 생깁니다. 원고 설정이 `html: false`라 문서 안의 링크는 마크다운으로 씁니다 |
| `tests/` | 노출 회차·문구·링크 검증 테스트(5.4) |

### 5.2 설정 예시

```json
    "naver": "https://mkt.shopping.naver.com/…",
    "coupang": "https://…"
  },
  "placements": [

    },
    {

```

- `links.naver`에는 스마트스토어센터에서 발급한 마케팅 링크, `links.coupang`에는 쿠팡 윙에서 확인한 마이샵 다이렉트 링크를 넣습니다.
- 회차별 성과를 따로 보려면 배치마다 `links`를 덮어써 서로 다른 링크를 넣습니다.
- 허용 도메인 목록은 실제 발급받은 주소의 도메인으로 정합니다.

### 5.3 동작 규칙

- **링크**: `target="_blank" rel="noopener"`로 새 창에서 열고, 접근성 이름에 '(새 창)'을 붙입니다.
- **접기**: 기존 `family-library:*` 규칙을 따라 `family-library:afterword-hidden`에 기억합니다. 저장이 막힌 브라우저에서는 매번 보입니다.
- **추적 없음**: 사이트에는 추적 스크립트나 픽셀을 넣지 않습니다. 성과는 판매자센터 통계로 봅니다.
- **인쇄·다크 모드·글자 크기**: 카드가 `.episode-end` 안에 있어 기존 인쇄 규칙으로 숨겨집니다. 색은 기존 토큰, 글자는 `--font-ui`·`--font-meta`를 써서 화면 모드와 글자 크기 설정을 그대로 따릅니다.
- **좁은 화면**: 좁은 화면이나 큰 글자에서는 두 버튼을 위아래로 쌓습니다. 반응 버튼이 이미 쓰는 처리와 같은 방식입니다.
- **삽화**: 기존 `ResponsiveImage`로 지연 로딩합니다.

### 5.4 테스트 계획

- [ ] 카드가 23화와 외전에만 보이고, 18화와 1화에는 없다 (Playwright)
- [ ] 카드 첫 줄에 '가족이 운영하는' 문구가 있다
- [ ] 링크가 새 창으로 열리고 접근성 이름에 '(새 창)'이 들어 있다
- [ ] '접기'를 누르면 새로고침 뒤에도 숨겨져 있다
- [ ] `afterword.json`의 회차 ID·삽화 ID가 없거나 링크가 허용 도메인이 아니면 `npm test`가 실패한다
- [ ] 320px 화면과 '아주 크게' 글자에서도 버튼 문구가 한 줄이고 높이가 56px이다 (기존 이동 버튼 테스트와 같은 기준)

## 6. 수익 최대화 세 가지

### 6.1 판매자 전용 링크로 마진 늘리기

같은 독자가 같은 쌀을 사도 어떤 링크로 들어왔는지에 따라 판매자 몫이 달라집니다.

| 채널 | 일반 상품 주소 | 판매자 전용 링크 | 판매 1건당 차이 |
|:---|:---|:---|:---|
| 네이버 | 2.73% (약 953원) | 마케팅 링크 0.91% (약 318원) | **약 635원** |
| 쿠팡 | 10.6% 가정 (약 3,699원) | 마이샵 3.5% (약 1,222원) | **약 2,480원** |

*34,900원 상품 기준, VAT 별도. 네이버 결제수수료는 두 경우에 똑같이 붙으므로 차이에서 뺐습니다.*

- **독정RPC가 쿠팡 판매자라면 파트너스는 쓰지 않습니다.** 카테고리 수수료 10.6%를 내고 3%를 돌려받는 셈이라 순부담이 7.6%입니다. 마이샵(3.5%)보다 판매 1건당 약 1,430원 불리하고, 가족이 링크로 사면 계정 정지 사유도 됩니다.
- **판매자가 다른 업체라면** 파트너스(약 3%)가 서재에서 얻을 수 있는 유일한 수수료입니다. 이때는 쿠팡이 요구하는 대가성 문구를 카드 첫머리에 넣습니다.
- **카드에서는 네이버 버튼을 앞에 둡니다.** 아이템위너 경쟁이 없고, 첫 구매가 스토어 알림받기·정기구독·선물하기로 이어질 수 있습니다. 쿠팡은 로켓배송에 익숙한 독자를 위한 두 번째 버튼입니다.
- **회차별 성과를 봅니다.** 배치마다 링크를 따로 발급하거나 `nt_source=memoir&nt_medium=story&nt_detail=ep23` 같은 NT 파라미터를 붙입니다. 다만 마케팅 링크에 NT 파라미터를 붙여도 0.91%가 유지되는지는 확인된 자료가 없으니 소액 주문으로 먼저 시험합니다.

### 6.2 정기구독과 알림받기로 재구매 만들기

- **쌀은 떨어지면 다시 사는 물건입니다.** 2025년 소비량 기준으로 2인 가구는 한 달에 약 9kg을 먹습니다.
- **카드의 네이버 링크를 정기구독이 켜진 상품으로 연결합니다.** 스마트스토어 정기구독은 2021년 도입됐고, 판매자가 배송 주기와 할인율을 정하며 별도 이용료가 없다고 보도됐습니다.
- **효과(가정치)**: 34,900원 상품을 5~6주마다 받으면 한 집에서 연 30만 원대가 나옵니다. 정기구독 독자 열 집이면 연 300만 원대입니다.
- **이야기와도 맞습니다.** 21화의 2002년 직거래 원칙("소비자에게는 갓 찧은 신선한 쌀")과 23화의 저온 사일로가 "큰 포대를 한 번 사기보다 갓 찧은 쌀을 다달이 받으세요"라는 제안의 근거가 됩니다.
- **알림받기**: 스토어 알림받기로 햅쌀 출하와 설 선물 시기를 알립니다.
- **주의할 점**: 햅쌀로 바꿔 보낼 때 생산연도가 다른 쌀을 섞으면 안 되고, 도정일 표시는 실제와 맞아야 합니다. 구독 해지·건너뛰기·환불 규정은 상세 페이지에 미리 적어 둡니다.

### 6.3 선물 에디션과 포장 QR로 새 고객 만들기

- **선물 상자**: 실제 판매하는 소포장 2~3종에 회차 수채화와 "내 논을 파는 한이 있어도, 농사지은 사람 볏값은 밀려선 안 된다." 문장을 담은 카드, 자서전으로 가는 QR을 함께 넣습니다.
- **순환 구조**: 선물 받은 사람이 QR로 이야기를 읽고 23화나 외전 카드에서 처음 구매합니다. 그 사람이 다시 선물을 보내면서 고리가 이어집니다.

```
  구매자 ──선물──▶ 받는 사람 ──QR──▶ 자서전 독자
     ▲                                    │
     └────── 23화·외전 카드에서 첫 구매 ◀──┘
```

- **가족 독자에게는 선물이 구매 경로입니다.** 가족은 쌀을 따로 살 일이 거의 없으니, 선물 에디션이 준비되면 외전 카드에 '선물로 보내기' 링크를 더합니다. 거래처 명절 단체 주문도 같은 상품으로 받습니다.
- **시기**: 지금은 햅쌀 출하기입니다. 다음으로 큰 시기는 2027년 설(2월 초)이므로 1월 중순 전에 상품과 카드를 준비합니다.
- **수채화 권리 확인**: 포장에 인쇄하기 전에 권리를 확인합니다. [`content/ref_images/manifest.json`](../content/ref_images/manifest.json)에 참고 사진 상당수가 '재사용 허가·라이선스 미확인'으로 기록돼 있습니다.
- **QR 주소**: 인쇄할 QR은 `mjbae.github.io/bae-memoir`가 아니라 가족이 소유한 도메인의 리디렉트 주소로 만듭니다. 저장소 이름이나 계정이 바뀌면 이미 인쇄한 QR이 모두 작동하지 않게 됩니다.
